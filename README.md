# 廣東話機舖 Canto Arcade

A pixel arcade for learning Hong Kong Cantonese (Yale romanization). Walk up to a machine and play:

- **香港通 Hēunggóng Tūng** — a pixel field guide to Hong Kong: places, districts, MTR stations, ferries.
- **數字 Soujih · Canto Numbers** — hear it or see it, type it in Yale.

Play: https://chapagetti852.github.io/canto-arcade/ · arrow keys / WASD or tap to walk, Space or tap ▶ to play.

Built with Phaser 4. Fonts: Fusion Pixel, Silkscreen, VT323 (SIL OFL).
